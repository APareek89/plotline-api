Plotline v3 — the marketing studio pipeline

User context in, finished creative out. The organising principle is the cost ladder: text is effectively free, images are cheap, video dominates — so every expensive commitment gets a cheap, rejectable artifact in front of it, and no gate artifact costs more than about 5% of the stage it protects.

AGENT — an LLM call FUNCTION — deterministic server code GATE — flow stops for you free cheap (images) real spend (video)

Both paths write the identical CampaignContext — path b is elicitation UX, not a second data model. Uploads travel as structured ids and are applied server-side, so a model that ignores them cannot lose your file.

  • claims_confirmed — one tap. Confirming grants permission to make claims; it does not gate the start. An unconfirmed list is candidates, not permissions.

Briefbrief
free
GATEcampaign_brief

“Are we making the right ad?” — and it locks the format constraints everything downstream inherits. Derived from the three cards, so no new typing.

  • The one thing they remember renders largest — if you read one line, that's it.
  • proof_points ⊆ confirmed claims, or blocked naming the claim.
  • aspect_ratios validate against the same spec table the Ad Card enforces.
  • Two ideas joined by “and” warns, never blocks — a heuristic must not make the brief harder to produce than the ad.

Styletemplates
free
GATEtemplate_picker style_blockskippable

A named, versioned string injected verbatim into every visual prompt — the cheapest consistency mechanism there is. Skip yields a neutral default block, never an absent one.

  • Realism dial (editorial / natural / documentary) — counter-intuitive and load-bearing: faces read as credible because of pores and asymmetry.
Scriptscript
free
GATEhook_rack

One locked body, many hooks. That structure is what makes variant testing affordable — a hook swap re-renders one shot, not the film.

  • W1 words-per-second — pure arithmetic, recomputed server-side. Over the per-language ceiling the line is rushed, clipped, and lip-sync collapses.
  • W2 emotion required — without an explicit read the model carries the previous line's delivery into this one.
  • W3 loanwords — forced translation is the tell that an ad was machine-made.
Shot boarddetail
free
GATEshot board the last free gate

Approve the film before it exists — and see the full cost of everything after it. The board, not the MP4, is the source of truth.

  • B1 one beat per clip — a two-action beat is auto-split and the split is recorded.
  • B2 runtime budget — cast size is an output of duration. Stops a twenty-second film with four protagonists.
  • B3 reference slots — forces drop-or-split and never truncates; a silently dropped product ref is how label drift enters a campaign.
  • B4 motion complexity — one short clip holds one camera move.
  • Model ids come from config, never from the model. route_reason is visible.
Canoncanon
cheap · reusable
GATEcanon_sheet ×4 kinds skippable

Cast, product, environment, voice — workspace-global library entities. The retention mechanic: campaign two is cheaper because the canon already exists.

  • Geometry risk — product accuracy is harder than face consistency, and packaging text is the hardest part. risk_notes force extra ¾ views.
  • Voice auditions on the real final line, never a demo reel. A non-English locale needs a blocking native-speaker sign-off.
  • Skipping is a costed, recorded choice — expect identity drift after a few shots.
Keyframeskeyframes
cheap
HARD GATE — never skippable keyframe_board

Lock the film as stills. Costs roughly a fiftieth of the motion it protects. No video is generated until every frame is approved. For an image campaign the keyframes are the deliverable.

  • Six checks per frame: face · hands · product geometry · label legibility · composition · safe area.
  • Region repair, not full regeneration — regenerating discards everything already correct.
  • Any prompt enhancer is forbidden from touching canon refs, claims or the style block.
Cost confirmgenerate
real spend
COST GATE — not configurable model_confirm

Cost is shown before it is spent, every time, plus an explicit user event. Single-vs-variants is always asked. No setting removes either — they are not gateable stages, and naming one in the policy is an error rather than a silent no-op.

Creativecreative
real spend
GATEcreative_set TakeReject

Per-asset accept / re-roll. Rejects are classified — “make it better” is not a repair instruction, so each of the five causes proposes its own patch.

  • One variable per retry — two simultaneous edits make the next result uninterpretable.
  • Review the whole clip, not frame one: frame-chained transitions go artificial mid-move.
QCqc
free
never skippableqc_report

Three tiers, because a flat pass/fail list either blocks a dated campaign over a continuity slip or gets ignored for crying wolf.

  • Always blocking: uncleared rights · a claim not in the confirmed list · a banned word · a missing locale sign-off. Claims are re-checked at the end, because copy drifts during production.
  • An accepted defect needs a written rationale — “ship it anyway” must be auditable, not a shrug.
  • An unwired detector reports skip, never pass.
  • Platform policy is surfaced as “needs a check against <platform>'s current rules” — an instruction to a human, never a verdict.

Per-placement copy, ratios, naming string, export bundle. The variant matrix shows the reuse map — a hook-axis variant re-renders exactly the hook shot, and that ratio is the business case for the shot board.

Every node checkpoints on success, so a failure never discards work that already succeeded and was paid for.

Why one reviewer

Three blind seats plus a chair were four LLM calls whose combined product was a single Feedback object — each seat judged one lens and the chair's whole job was to merge them back together. On the production model that was most of a ~15 minute rumination; the chair alone took 477s.

The Marketing Expert emits that Feedback directly, so the consolidation step is removed rather than made faster.

What the reviewer must refuse

  • Angle fatigue — saturation is a count over a corpus and it has none, so the lens always declares insufficient data.
  • Platform ad policy — it never states what a rule says, only what a human must check. An invented rule is the worst thing this product can emit.
  • Numbers — every judgment is a direction, never a magnitude. Quoted text is exempt, because quoting an offending claim is the job.

Settings — how deep the pipeline runs

A gate mode controls whether the flow pauses. It never controls whether the artifact is produced — downstream stages consume upstream artifacts, and the audit trail stays complete however fast you move.

ModeBehaviourWhere it is legal
reviewProduced, emitted, flow blocks for you. The default everywhere.every gateable stage
autoProduced, emitted, audited — flow continues. Reviewable after the fact.every gateable stage except the hard gates
skipThe work is not done, and the trade-off is stated.only templates and canon

Presets: Full craft (all review) · Fast (brief/templates/script/canon auto) · Volume (all auto except keyframes and QC; 2 takes, 3 variants).
